# Calendario de contenido - GTA 6 Noticias (primeras 7 semanas)

Ritmo sugerido: 3 articulos por semana (lunes/miercoles/viernes), ajustable
segun tu disponibilidad. El orden esta pensado para publicar lo mas facil de
verificar primero, y dejar las piezas mas largas (guias, teorias) para cuando
ya tengas el flujo de publicacion automatizado y comodo.

Categorias usadas (deben coincidir con las que ya tienes en `hugo.toml`):
`Noticias`, `Guias`, `Teorias`, `Personajes`, `Mapa`

**Importante:** en los articulos de categoria `Teorias`, deja siempre claro
en el texto que es especulacion tuya, no informacion confirmada por Rockstar.
No mezcles opinion con hechos verificados sin distinguirlos.

## Como usar este calendario

1. Cada vez que vayas a escribir uno, usa `guia-estructura-articulo.md` como
   molde (front matter + estructura de Markdown).
2. Antes de publicar articulos de categoria `Noticias`, verifica la
   informacion con una busqueda rapida — las fechas/precios/detalles pueden
   cambiar entre que armamos este calendario y que tu escribas el articulo.
3. Marca aqui mismo (agregando una palabra "LISTO" junto al titulo, o
   simplemente tachandolo) los que ya publicaste, para no perder el hilo.
4. Cuando termines estos 21, ya tendras contenido suficiente para aplicar a
   AdSense (revisa el checklist que armamos antes) — ese es un buen punto
   para hacer una pausa y evaluar como esta yendo el trafico antes de seguir
   con un segundo ciclo de articulos.
